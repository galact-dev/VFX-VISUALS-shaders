# VFX-VISUALS-shaders
VFX Shaders — Vibrant Visuals Shaders Um shader para Minecraft focado em visuais vibrantes, iluminação atmosférica e um estilo Golden marcante. O VFX busca transformar a atmosfera do Minecraft com cores mais vivas, céus detalhados e uma iluminação cinematográfica, mantendo a identidade visual do jogo.
